# Plan Project

Use [project planning](../../AI_WORKFLOW.md#project-planning) for shared branch
and PR rules. In a `plan/<name>` worktree, read the current project plan and
update `docs/project-plan.md` with the project's Goal, Significance,
Requirements, and milestones. Route the PR through `review-task`. Use
`new-project-intake` first when the idea is still too vague for a project plan.
