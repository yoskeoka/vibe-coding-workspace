# Kenney のゲーム素材・ツール・スターターキット

## 要約

Kenney のサイトは、無料ゲーム素材、ツール、starter kit のカタログと入口です。素材一括パッケージも提供し、supporter club では先行アクセスなどの追加特典があります。starter kit は free / open source と紹介され、ツールは複雑なソフトウェアや framework の知識なしに3Dモデルを作れる手段として案内されています。

## ワークスペースでの意義

統一感のある仮素材や完成素材をすばやく探したい prototype に使えます。starter kit は新規ゲームの初期設定負担も下げられます。配布時には各 asset pack に付属する license を確認してください。トップページだけでは個々の素材の license は確定できません。
