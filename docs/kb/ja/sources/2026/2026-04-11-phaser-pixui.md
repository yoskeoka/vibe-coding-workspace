# Phaser PixUI: ピクセルアートゲーム向けオープンソース UI ライブラリ

## ここで重要な理由

ワークスペースにはゲーム系プロジェクトが複数あり、Phaser ベース試作で retro visual を採るなら、pixel-art 向け UI stack が時間短縮につながる可能性がある。

## 要約

- PixUI は Phaser 4 の pixel-art game 向けに特化したオープンソース UI ライブラリとして紹介されている。
- crisp な integer scaling と、カスタマイズ可能な UI component を重視している。
- retro game でありがちな、汎用 UI のぼやけや噛み合わなさに対する解として位置づけている。

## ワークスペースでの含意

- 将来の Phaser プロジェクトで、widget を全部自作せずに sharp な pixel UI を出したいときに relevant。
- まだ確定依存ではなく、tool capability として追跡する段階。

## フォローアップ

- Phaser ベースの game prototype が UI polish 段階に入ったら再評価する。
