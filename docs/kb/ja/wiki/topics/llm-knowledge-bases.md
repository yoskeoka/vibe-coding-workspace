# LLM ナレッジベース

## 要約

中核パターンは、LLM に curated source から compiled Markdown wiki を継続保守させることです。毎回ブックマークや検索から再発見するのではなく、durable な知識面を育てます。

## このワークスペースに合う理由

- `docs/` 配下の Markdown はそのまま AI の作業コンテキストになる
- source note と wiki page を分けると provenance を維持しやすい
- `index.md` と `log.md` が human/AI 両方の入口になる
