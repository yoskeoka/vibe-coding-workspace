# Next2D

## Current signal

`Next2D` is a strong reference for owning more of the browser-game stack, from runtime and framework conventions to animation tooling and AI-facing context integration.

## Notes

- The system is described as `Player + Framework + AnimationTool`, not just an engine runtime.
- The runtime side emphasizes `OffscreenCanvas`, worker-based rendering, `Transferable` `ArrayBuffer` handoff, buffer reuse, and object pools to protect framerate.
- The framework side is grounded in `MVVM + Clean Architecture + Atomic Design`, making it relevant as a retrieval anchor for structured game UI/application architecture.
- The article also points to a `Next2D` `MCP` server, which makes the stack relevant to future AI-assisted development flows, not only rendering performance.
