# vim-learning-game

## Relevance

This project is still early enough that references about UI style, browser-game tooling, and AI-assisted game prototyping can meaningfully shape implementation choices.

## Current takeaways

- Track Phaser-related signals even if the final engine differs.
- Pixel-art-specific UI notes may become useful if the project adopts a retro visual direction.
- Branching narrative authoring applies if lessons become adaptive tutorials rather than fixed levels. The project should treat mode unlocks, player mistakes, hints, and callbacks as explicit state with visible feedback and validation, not just scattered dialogue text.
