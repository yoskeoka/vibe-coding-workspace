# Claude Code Game Studios

## Summary

`Donchitos/Claude-Code-Game-Studios` is a Claude Code project template for taking a game from idea to prototype and then growing it. `/prototype` asks a few focused design questions, writes a reviewable `design/game-brief.md`, creates a browser game in `prototypes/<name>/`, and runs a bounded browser check. The handover distinguishes checks performed from playtesting by a person.

The project can grow an accepted prototype into a Vite + TypeScript web project. It also documents `/start`, `/next-step`, `/brainstorm`, `/setup-engine`, and `/project-stage-detect`, plus Web, Godot, Unity, and Unreal engine setups. A `project.yaml` controls rigor and the amount of documentation, QA, and review. The repository explicitly says its engine routes and deep system design have not yet had the same evaluation as the browser prototype path.

## Workspace relevance

This is a concrete comparison point for AI-assisted game workflows: it front-loads a short brief, makes prototypes easy to play, and treats browser checks and human play as separate evidence. Its own evaluation caveats are useful when judging claims about engine support. Inspect the repository's current setup and permission rules before adopting the template.
