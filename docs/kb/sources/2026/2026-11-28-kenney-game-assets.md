# Kenney game assets, tools, and starter kits

## Summary

Kenney's site is a catalog and entry point for free game assets, tools, and starter kits. It also offers an all-in-one asset package and a supporter club with early access and additional materials. The starter kits are presented as free and open source; the site describes its tools as a way to create 3D models without needing complex software or framework knowledge.

## Workspace relevance

Kenney is a practical asset source for prototypes that need coherent placeholder or production-ready art quickly, and its starter kits can reduce the setup burden for a new game project. Check the license attached to each asset pack before shipping; the home page alone does not define the license for every item.
